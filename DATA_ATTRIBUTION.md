# Data attribution / redistribution status

The supplied archive contains rendered raster XYZ tiles only. No source metadata, copyright notice, provider name, or redistribution license was present in the archive.

Therefore this repository treats the **code** and the **tile data** as separate things:

- Code in this repository: MIT licensed.
- Raster tile content / `basemap.pmtiles`: **license not established by this repository**.

Before publishing `basemap.pmtiles` publicly, the repository owner should document the original provider, license/permission, required attribution text, and any redistribution restrictions here. Processing a supplied archive into PMTiles does not itself grant redistribution rights.
