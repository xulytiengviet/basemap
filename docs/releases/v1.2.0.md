# v1.2.0 — Embeddable CDN SDK

**Developer:** Long Ngo  
**Code license:** MIT  
**Dataset payload:** unchanged from v1.1.0

This release adds a browser SDK designed for copy-paste WebGIS embedding through jsDelivr while preserving the same canonical PMTiles raster payload.

## New

- `sdk/basemap.js` — global browser SDK with automatic dependency loading.
- `sdk/basemap.esm.js` — ES module API.
- one-line auto-mount through `<script data-target="map">`.
- `LongNgoBasemap.create()` / `addTo()` / `getMetadata()` / `ready()`.
- direct PMTiles loading from the latest GitHub Release asset.
- MapLibre GL JS 5.13.0 + PMTiles JS 4.5.0 pinned by the SDK.
- `examples/embed/index.html` — standalone CDN embed demo.
- CI syntax verification for the SDK.

<script src="https://cdn.jsdelivr.net/gh/xulytiengviet/basemap@v1.2.0/sdk/basemap.min.js" data-target="map"></script>
